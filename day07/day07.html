案例1：随机点名案例day2-94

业务分析： 1、点击开始按钮随机抽取数组的一个数据，放到页面中 2、点击结束按钮删除数组当前抽取的一个数据 3、当抽取到最后一个数据的时候，两个按钮同时禁用(写点开始里面，只剩最后一个数据不用抽了) 核心：利用定时器快速展示，停止定时器结束展示 易错点： 1、pop是只删除数组的最后一个值 shift删除第一个值 2、splice：删除或者添加 splice(start, deleteCount, item1, item2, /* …, */ itemN) 3、indexOf和findIndex JavaScript 中，findIndex 要求传入一个回调函数作为参数 如果你只是找一个简单的字符串在数组里的位置，用 indexOf(value) 最简约。 如果你是找满足某个复杂条件的成员（比如对象里的某个属性），才用 findIndex(item => ...)。

案例2：轮播图完整版案例day2-96~97

业务分析： 核心：利用定时器快速展示，停止定时器结束展示 这个案例在day06.html中已经实现 增加功能 鼠标经过暂停定时器；鼠标离开开启定时器 学而知新：CSS居中汇总
text-align: center → 只对块级容器里的行内/行内块内容居中，flex 子项不吃这一套
align-items: center → 控制交叉轴对齐（上下居中），不会左右移动
margin: 0 auto → 用在自己身上，只能让块盒子本身在父层居中，不会管里面的子项怎么摆
居中口诀：
| 场景 | 口诀 | 给谁写 |
| ----------------------- | ------------------------ | ----------- |
| 文字、链接、图片等**行内/行内块**左右居中 | `text-align:center` | **父元素** |
| **定宽块级盒子**本身左右居中 | `margin:0 auto` | **自己** |
| **flex 子项**在**主轴**居中 | `justify-content:center` | **flex 容器** |
| **flex 子项**在**交叉轴**居中 | `align-items:center` | **flex 容器** |
